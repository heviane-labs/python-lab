# 🐍 Python Lab

Repositório dedicado a estudos práticos, testes e experimentos utilizando o ecossistema Python. O objetivo é explorar desde fundamentos da linguagem até automações, manipulação de dados e integração com bibliotecas populares.

---

## 🎯 Objetivos

- Praticar conceitos da linguagem e boas práticas de desenvolvimento (PEP 8, tipagem, virtualenvs).
- Desenvolver scripts úteis para automação de tarefas do dia a dia.
- Testar e documentar o uso de bibliotecas de terceiros (ex: `openpyxl`, manipulação de arquivos, APIs, etc.).

## 🚀 Como Executar os Exemplos

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/heviane-labs/python-lab.git
   cd python-lab
   ```

2. **Crie e ative um ambiente virtual (recomendado):**
   ```bash
   python -m venv .venv
   # No Windows (PowerShell):
   .venv\Scripts\Activate.ps1
   # No Windows (CMD):
   .venv\Scripts\activate.bat
   # No Linux/Mac:
   source .venv/bin/activate
   ```

3. **Navegue até o exemplo desejado e siga as instruções contidas no `.md` correspondente dentro de `examples/`.**
